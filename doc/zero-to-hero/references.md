The Rust Playground — run Rust code in your browser, no install required. Useful for trying examples from this lesson before Lesson 1.1.2 covers installation: 
https://play.rust-lang.org/

The Rust Programming Language ("The Book") — the primary official guide to the language: 
https://doc.rust-lang.org/book/

Foreword & Introduction — framing for why Rust exists: 
https://doc.rust-lang.org/book/ch00-00-introduction.html

Chapter 4: Understanding Ownership — the definitive treatment of ownership, borrowing, and slices: 
https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html

Rust by Example — runnable examples (each has a "Run" button that opens in the Playground), lighter on prose than The Book: 
https://doc.rust-lang.org/rust-by-example/

Rustlings — small hands-on exercises for learning syntax: 
https://rustlings.rust-lang.org/

Standard Library API docs: 
https://doc.rust-lang.org/std/
